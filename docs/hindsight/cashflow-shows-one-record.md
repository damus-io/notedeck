# The CLI shows one record by its id

No command prints one transaction's legs and `raw-*` metadata by its `; id:`,
so deciding an ambiguous unknown means exporting its day and finding the block.

- headway:cashflow/key-economy-raw — the cashflow skill has to teach `export --begin <day> --end <next day>` plus a search for `; id: <record-id>` as the way to read a row's merchant, city and description, because `unknown --json` gives only ids and `report reg` drops ids and metadata
